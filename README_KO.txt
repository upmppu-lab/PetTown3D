Pet Town 3D v11 - 독립형 3D 캐릭터 미리보기

기반: v10 안전 복구 버전 + 새로운 시각 전용 미리보기

핵심: 게임 캐릭터 GameObject를 Instantiate하지 않습니다.
Transform/메시/스킨 메시 렌더러만 새로 만들며 플레이어 이동, 카메라, 게임 스크립트를 복제하지 않습니다.
미리보기 전용 Layer 30, Camera, RenderTexture를 사용합니다.
원본 색상 변경 후 미리보기 색상을 갱신합니다.

설치: Play 중지 > ZIP 내 Assets 폴더 덮어쓰기 > Unity 컴파일 완료 후 Play
검증: 꾸미기 열기/색상 선택/닫기/WASD 및 클릭 이동 확인
주의: 모델의 정면 축이 -Z가 아닐 경우 미리보기 방향 조정이 필요할 수 있습니다.
Unity Editor 실행 검증은 수행하지 않았습니다.
