# 매장 운영 시스템 추가 — 2026-10-26

기존 건설·가구·NPC 이동·저장 방식에 선택적인 운영 데이터를 추가했습니다. 직원이나 물품을 실제 테스트 마을에 무료로 삽입하지 않았습니다.

## 새 파일

- `Scripts/PetTownShopOperationsState.cs`: 고용·교육·급여·휴무·미지급 정산, 배송 주문/수령, 미용 키트/미용 상태, 안내 퀘스트 카운터/수령 및4종 발견 기록. 선택적인 버전 필드로 기존 저장에 새 데이터를 초기화합니다.
- `Scripts/PetTownGame.Operations.cs`: 직원/급여/미용대/배송 메뉴. 실제 가구를 작업대로 지정하고 NavMesh 접근 가능 여부를 검사합니다.
- `Scripts/PetTownGame.Employees.cs`: 기존 NPC 생성/애니메이션 헬퍼를 재사용하는 독립 직원 목록. 청결·돌봄·배송·계산·미용5직종이 실제 경로로 작업 지점에 도착해야 완료됩니다. 중복 작업 예약, 대상 이동·소멸, 미지급/휴무, 경로 시간 초과를 처리합니다.
- `Scripts/PetTownGame.Journal.cs`: 먹이/목욕/놀이/분양/고용/배송/미용7개 안내 퀘스트, 보상 중복 수령 방지, 현재 지원4종의 발견 도감.
- `Scripts/PetTownGame.PetPlay.cs`, `Scripts/PetTownPetPlayWindow.cs`:12초 장난감 터치 놀이. 최대10회, 점수에 비례한 상태 회복/경험치, 무입력·취소 보상 없음, 완료 콜백 중복 방지.

각 새 C# 파일의 `.meta`도 Unity가 생성했습니다.

## 기존 파일의 연결 변경

- `PetTownGame.cs`: 운영 메뉴20~25 연결, 매일 급여 처리, 유지비로 잔액이 음수가 되지 않도록 한도 적용. 모드 전환/컴포넌트 종료 시 놀이 예약 해제.
- `PetTownGame.Progression.cs`: 활성 플레이에서만 운영 갱신, 돌봄 카운터, 물품 가방, 기존 놀아주기 버튼 연결, 놀이 중 중복 돌봄 방지.
- `PetTownProgressionState.cs`: 선택적 operations/version 저장, 미용 분양가20% 및 기록 보존.
- `PetTownPetCareState.cs`: 미용 플래그, 저장되지 않는 놀이 중 잠금, 잠긴 개체 분양 제외, 특수 동작을 일반 안기 동작으로 처리하지 않도록 검사.
- `PetTownResidentState.cs`: 분양받은 펫의 미용 기록 보존.
- `PetTownPetCareWindow.cs`: 미용 상태/버튼 및 놀이 화면으로 연결.
- `PetTownGame.CozyPresentation.cs`: 놀이 중 팝업 상태를 기존 HUD/입력 차단 질의에 포함.

## 게임 규칙

- 직원5직종, 직종별 최대5명. 레벨별 고용 조건, 고용비 증가, 교육 Lv10까지, 실제 일급/교육비를 표시합니다.

- 놀이 중인 개체는 직원 돌봄/분양과 충돌하지 않도록 잠깁니다. 취소/모드 변경/종료 시 해제되고 저장에는 잠금이 포함되지 않습니다.
