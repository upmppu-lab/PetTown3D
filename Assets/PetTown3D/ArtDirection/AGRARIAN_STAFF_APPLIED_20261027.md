# 농장·닭장·목장 직원 자동화 — 2026-10-27

농장 관리사(사장 Lv.4, 첫 고용 1000G)와 목장 관리사(Lv.5, 1300G)를 추가했습니다. 기존 고용비 증가·담당별 5명 정원·급여·교육·휴무·미지급 정산 규칙을 사용합니다. 기본 일급은 각각 195G와 225G이며 교육 후 기존 배율로 증가합니다. 고용 계약만으로 일을 시작하지 않으며 한 관리사에게 하나의 실제 농장 또는 목장을 배정합니다.

## 사용과 실제 동작

직원 관리 → 근무지 배정 또는 농장/목장 관리 → 직원 배치에서 직원을 선택하고 직원 자동 업무를 켭니다. FarmRecord/RanchLot의 staffService는 기존 저장에서 false이므로 수동 관리가 유지됩니다. 직원의 facilityId에 기존 건물 ID를 연결하며 위치·씨앗·동물 ID를 변경하지 않습니다.

농장 관리사는 기존 9개 밭의 오늘 필요한 물주기와 익은 작물 수확을 처리합니다. 닭장이 있는 경우 보유 닭 먹이로 급식하고 물·청소·달걀 수집도 합니다. 목장 관리사는 보유 가축 먹이로 급식하고 물·청소·준비된 우유/양털 수집을 처리합니다. 밭 앞, 닭장 문 앞, 목장 중앙 관리 통로의 실제 지점으로 이동한 뒤 기존 직원 업무 시간을 마쳐야 완료됩니다. 전용 물뿌리개·급이·착유 애니메이션을 새로 만든 작업은 아닙니다.

경로 완전성·물·높이·소유 구역·월드 변경 번호를 확인합니다. 같은 밭/닭장/가축 관리 작업은 직원끼리 중복 예약하지 않습니다. 다른 밭은 두 관리사가 나눠 처리할 수 있습니다. 도착 전에는 재료나 생산물을 처리하지 않습니다. 완료 시점에 다시 유효성을 확인하고 기존 Water/Harvest/Feed/Clean/Collect를 호출하므로 수동 관리와 경쟁해도 중복 차감·수확되지 않습니다.

먹이가 전체 미급식 개체 수보다 적으면 일부만 먹여 차감하지 않습니다. 수확 창고가 가득 차면 작물을 보존하고, 달걀·우유·양털도 기존 보관 상한을 지킵니다. 급여 미지급·휴무·배정 해제·자동 업무 끄기·대상 철거/변경 시 중단하며 다음 날에는 기존 날짜 규칙에 따라 필요한 업무를 다시 찾습니다. 중간 이동/작업 예약은 런타임 정보이며 재시작 후 다시 출근합니다. 자원 처리는 완료 때만 저장되므로 재시작으로 미완료 자원이 차감되지 않습니다.

씨앗 구매·심기·먹이 구매·물품 판매·동물 구매·돼지 출하는 직접 선택합니다. 자동 업무가 동물을 판매하거나 돼지를 출하해 고기를 만들지 않습니다. 작물/달걀/우유/양털 수집 XP와 일일 의뢰 활동은 기존 수동 수집과 같은 값으로 1회 기록합니다.

## 구현 파일

신규 PetTownAgrarianWork.cs는 상태 기반 작업 목록/유효성/자원 처리를, PetTownGame.AgrarianStaff.cs는 실제 현장 경로·예약·완료를, PetTownGame.AgrarianStaffUI.cs는 모바일 배정/관리 창을 담당합니다. 직원 루프·고용 목록·농장/목장 관리에 연결했습니다. 기존 원본 팩, 지형·건물·가구 배치, 플레이어/NPC 이동·애니메이션 코어와 공통 UI 테마는 변경하지 않았습니다.
