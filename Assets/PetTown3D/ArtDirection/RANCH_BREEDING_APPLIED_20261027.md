# 목장 개체 관리·판매·번식 — 2026-10-27

목장 관리에서 가축을 맞이할 때 암컷/수컷을 선택합니다. 각 개체 행을 열면 성별·성장·생산·세대를 확인하고 개체 판매 또는 짝 선택으로 이동합니다. 목장 번식에서 새 부모 선택·진행 취소·탄생 기록을 관리합니다. 기존 목장 에셋과 개체 모델/성장 비주얼을 사용합니다.

## 번식과 출생

- 같은 종류의 성체 암수 한 쌍, 오늘 먹이·물 완료, 청결60 이상이 필요합니다. 진행 중인 부모와 휴식 중인 개체는 중복 선택하지 못하며 부모·자식/공통 부모 관계도 제외합니다.
- 시작하면 같은 종류의 새끼1마리 자리를 예약합니다. 기존 젖소3/양4/돼지3 정원 안에서 예약하며 맞이하기가 이 자리를 사용할 수 없습니다.
- 실제로 부모 모두에게 먹이·물을 주고 청결40 이상을 유지한 두 번의 연속된 새날을 지나면 새끼1마리가 태어납니다. 부족한 날은 대기하고 날짜를 건너뛰어 출생을 소급하지 않습니다. 현재 맵에 실제 존재하는 목장만 진행합니다.
- 부모는 시작일부터3일 휴식합니다. 취소하면 예약만 풀고 남은 휴식은 유지합니다. 진행 중인 부모는 개체 판매와 돼지 출하에서 제외합니다.
- 새끼는 새 고유 ID, 부모 ID/이름 기록, 세대, 성별, 출생일을 저장합니다. 크기45%에서 태어나 기존 먹이·물·청결 기반2일 성장 규칙으로 성체가 됩니다. 개체 정원과 출생 기록은 재시작 뒤에도 유지하며 같은 날짜의 중복 출생을 막습니다.

## 판매·생산

- 어린 개체는 구매가의30%, 성체는60%의 반올림 가격으로 판매합니다. 실제 선택 개체를 제거하고 해당 골드를 한 번만 지급합니다. 가방 생산물은 건드리지 않습니다.
- 개체에 수집 대기 중인 생산물이 있으면 먼저 모으도록 안내합니다. 번식 부모·없는 개체·골드 한도 초과 판매는 아무 자원도 바꾸지 않습니다.
- 돼지 고기 출하는 별도로 유지합니다. 출하하면 선택 성체 돼지가 빠지고 고기3개가 생깁니다. 번식 중인 부모는 출하할 수 없습니다.
- 수컷 소는 번식용으로 우유를 생산하지 않습니다. 기존 성별 없는 젖소는 암컷으로 이관해 원래 우유 생산과 준비된 생산물을 보존합니다. 양털은 암수 모두 생산합니다. 성별에 따른 별도 외형 모델은 추가하지 않았습니다.
- 목장 관리사의 기존 자동 먹이·물·청소·우유/양털 수집은 유지합니다. 새끼도 돌봄 대상에 포함합니다. 번식 시작·취소·구매·판매·출하는 플레이어가 선택합니다.
