# 카페·예방검진 기초 운영 — 2026-10-26

현재4종 개체/주민/건물/저장 구조에 맞춰 수동 서비스 운영을 추가했습니다. 기존 2D 게임의 `cafecore.js`, `hospcore.js`, `README_HANDOFF.md`를 동작 참고 자료로 분석했습니다. 원본의 농장·질병·전문 진료실 전체를 이식했다고 보고하지 않습니다.

## 사용 경로와 규칙

펫샵 관리 → 카페·병원 운영 → 실제 건설한 시설 선택.

- 영업 시작/마감, 선택적30초 자동 방문 안내, 직접 손님 선택, 소모품 구매, 시설 가구 배치, 수납 기록.
- 실제로 펫을 소유한 주민만 방문합니다. 기존 주민 객체와 NavMeshAgent를 잠시 시설 방문에 사용하고, 끝나면 기존 배회로 돌려보냅니다. NPC를 복제하거나 기존 이동/애니메이션 헬퍼를 교체하지 않습니다.
- 같은 주민/펫 중복 예약 금지. 같은 종류 서비스는 펫별 하루1회. 이동 가능한 테이블1개당1명, 시설별 최대4명. 계산대와 원목/낮은 테이블 필요.
- 카페: 입구→계산대→직접 조리 시작(재료1개,8초)→테이블→식사12초→계산대→직접 수납70골드→퇴장.
- 병원: 입구→접수4.5초→검진대→직접 예방검진 시작(소모품1개,10초)→수납대→직접 수납140골드→퇴장.
- 카페 재료5개100골드, 검진 소모품5개250골드. 예약된 미사용 소모품도 계산하여 초과 접수하지 않습니다. 작업 시작/수납은 실제 도착 확인이 필요하며1회만 처리합니다.
- 펫 경험치 카페1/검진2, 사장 경험치3/4, 주민 행복도3/2, 서비스 행복도0.4/0.6. 기존 레벨 보상만 적용합니다.
- 영업 마감은 신규 접수만 중단합니다. 대기180초 초과 시 방문 종료/미수납 처리. 사용한 소모품은 반환하지 않습니다.
- 앱 포커스가 없거나 시간이 멈추면 시설 진행을 멈춥니다. 진행 중 방문/소모품/결제/당일 이용 이력은 선택적 데이터로 저장합니다. 불러온 뒤 작업 지점에 다시 실제 도착해야 작업/수납을 할 수 있습니다.
- 시설 가구 배치는 기존0.5m 스냅/90도 회전/충돌 검사/소유 건물 좌표/저장을 재사용합니다. 하단 꾸미기는 다시 펫샵을 선택합니다. 기존 가구는 이동하지 않았습니다.
