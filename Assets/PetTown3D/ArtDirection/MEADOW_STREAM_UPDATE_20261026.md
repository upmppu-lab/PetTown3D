# 잔디·공터·강 추가 조정 — 2026-10-26

사용자 피드백: 잔디를 조금 연하게, 무성한 풀/낮은 풀/흙 공터를 자연스럽게 혼합. 강은 큰 반복 물결을 줄이고 물·강둑을 자연스럽게 표현.

## 적용

- 기존 실제 잔디 에셋 메시와 GPU 인스턴싱을 유지했습니다. 잔디 끝/뿌리 색을 밝고 덜 강한 녹색으로 조정했습니다.
- 512×512 분포 마스크를 새로 생성해 지면 재질과 CPU 잔디 배치가 동일한 데이터를 사용합니다. R=흙, G=식물 밀도, B=풀 높이, A=색 변화입니다.
- 무성한 구역을 유지하면서 짧고 듬성한 풀밭과 흙이 보이는 공터를 섞었습니다. 공터는 겹친 비대칭 영역과 여러 크기의 노이즈로 형태를 불규칙하게 만들었습니다.
- 공터 중심에는 기존 산발적 풀 외형도 숨기며, 가장자리로 낮은 풀이 이어집니다. 원본 에셋 삭제나 지형/충돌 메시 변경은 없습니다.
- 강의 큰 네온형 반복 무늬를 대비가 낮은 작은 잔물결로 변경했습니다. 흐름은 기존 강 중심선의 누적 거리 UV와 `_FlowSpeed=.025`를 유지합니다.
- 얕은 물/깊은 물 색 변화, 젖은 흙과 모래·자갈, 바깥 풀밭으로 이어지는 경계 폭에 변화를 주었습니다. 물 가장자리의 과도한 넓은 투명 블러는 추가하지 않았습니다.
- 강가 돌의 위치/크기/군집에 변화를 주고 원본 에셋 모델을 사용합니다. 새 장식에는 충돌체나 NPC 장애물을 추가하지 않습니다.
- 실제 마을 나무는 기존49개를 유지합니다. 독립 시안의 나무93개도 유지합니다.
