# 줌 잔디 경계 및 공통 모바일 창 수정 — 2026-10-26

## 변경 내용

- 잔디의 24/50 줌 경계와 70/110m 거리 경계에서 패치를 다른 개체 수로 다시 생성하던 처리를 제거했습니다. 카메라 줌은 원래 잔디 분포를 바꾸지 않습니다.
- 패치에 고정 배치를 캐시하고, 안정적인 무작위 순위에 따라 화면 전체의 표시 밀도를 연속적으로 조절합니다. 원거리 경량 Wispy 메시 전환도 개별 잔디에 분산하여 한꺼번에 바뀌지 않게 했습니다.
- 표시 목표는 약 16,000개 인스턴스입니다. GPU instancing·화면 밖 캐시 제거·프레임당 생성 예산을 유지합니다. 캐시에는 근거리 원래 개체 위치도 보관하므로 이전 희박한 패치 방식보다 CPU 메모리 사용은 늘어납니다. 3D 잔디가 전 지역에서 근거리와 동일한 밀도로 표시된다는 뜻은 아닙니다.
- 기존 밝은 잔디색·공터 마스크·흙·나무·강·원본 에셋은 바꾸지 않았습니다.
- 공통 창은 원래 Sprite의 아이보리색을 다시 사용합니다. 테두리·버튼·선택색은 원래 아트워크를 보존합니다.
- 회색 제목 바 불투명도는 80%→45%, 배경 어두움은 55%→35%로 조정했습니다. 기존에는 제목 바 뒤에 불투명한 창 종이가 있어 투명도를 낮춰도 게임 화면이 보이지 않았습니다. 이제 창 종이에 제목 바 영역만 둥근 투명 영역을 만들어 실제 뒤 화면을 보여 줍니다. 각 창의 전용 머티리얼을 사용하며 목록 카드에는 구멍이 생기지 않습니다.
- 기본 최대 창 폭은 420→360 기준 단위로 줄였습니다. 세로 화면 Safe Area의 86% 이내로 제한합니다. 720×1280에서는 기본 폭 약 576px로, 이전 약 672px보다 약 14% 좁습니다.
- 항목이 적을 때 창의 최소 높이를 낮췄습니다. 실제 성장 분류 1개 항목의 창 크기는 360×358로 확인했습니다.
- 목록 행은 실제 표시하는 이름·가격·보조 설명의 글자 묶음을 그림의 세로 중앙에 배치합니다. 작은 설명 상자가 글자를 통째로 숨기던 문제도 고쳤습니다. 펫 프로필 옆 설명도 프로필 중앙에 맞추고 좁은 화면의 자동 글자 크기를 제한했습니다.
