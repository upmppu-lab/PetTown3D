# 카페·병원 전문 직원 자동 업무 — 2026-10-27

카페 요리사(사장 Lv.4, 첫 고용 1200G)와 수의사(Lv.6, 2000G)를 추가했습니다. 기존 계산 담당을 카페·병원 한 곳에 배치해 수납도 맡길 수 있습니다. 기존 고용비 증가, 담당별 5명 정원, 교육·휴무·급여·미지급 정산 규칙을 사용합니다. 새 전문 직원은 근무 시설을 배정해야 일을 시작하며 기존 직원은 원래 펫샵 업무를 유지합니다.

## 실제 운영 흐름

직원 관리의 근무지 배정 또는 각 시설 운영의 시설 직원 배치에서 직원을 선택하고, 직원 자동 업무를 켭니다. 손님 자동 방문과 직원 자동 업무는 별개의 설정입니다. 기존 저장의 자동 업무는 기본 꺼짐이며 기존 수동 서비스를 그대로 이용할 수 있습니다.

요리사는 카페 계산대, 수의사는 병원 검진대의 이동 가능한 작업 지점을 찾아 실제로 걸어갑니다. 시설 내부·높이·물·NavMesh 완전 경로를 확인하고 손님의 반대편을 우선 탐색합니다. 주민·펫이 실제로 도착하고 직원도 자신의 작업 지점에 도착해야 시작합니다. 동일 방문에는 직원 한 명만 작업을 예약할 수 있습니다. 시작할 때 기존 재료를 1개 사용하며 교육 레벨에 따라 신규 작업 시간이 짧아집니다.

진행 중에도 직원의 배정, 급여·휴무, 위치, 가구 위치와 월드 변경 번호를 확인합니다. 직원이나 펫이 빠지면 시간이 멈춥니다. 작업의 남은 시간·사용한 재료·직원 소유권을 저장하므로 재시작 후 직원이 실제 도착해 재인계해야 진행됩니다. 직원 교체·휴무·미지급 급여·자동 업무 끄기 시 재료를 재차 차감하거나 작업 시간을 초기화하지 않습니다. 방문 관리의 직접 업무 이어하기로 수동 전환할 수 있습니다.

조리/검진 후에는 기존 식사·수납 이동을 따릅니다. 배치된 계산 담당이 주민·펫과 함께 수납 지점에 실제로 도착해 업무 시간을 마친 뒤 수납합니다. 기존 TakePayment의 영수증·하루 이용·중복 결제 보호를 사용합니다. 카페 활동을 UI와 상태 모델에서 중복 기록하던 부분도 상태 모델의 1회 기록으로 통일했습니다. 마감 후에도 이미 접수한 방문은 마칠 수 있습니다.
