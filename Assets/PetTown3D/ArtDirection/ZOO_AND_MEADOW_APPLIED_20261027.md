# 동물원 개편 및 잔디·돌길 경계 보완 — 2026-10-27

## 동물원

사용자가 첨부한 2-model.glb를 SourceModels/UserSavanna/SavannaPaddock.glb로 원본 보관했습니다. 원본은 Savanna paddock 장면으로, 코끼리·기린·얼룩말, 그늘막, 먹이통, 공, 목재 난간이 들어 있습니다. 이미지 3에 나온 동물원 전체 모델은 아닙니다. 사용자가 제공한 파일이며 외부 유료 구매는 하지 않았습니다.

기존 세 칸 사각 우리를 숲(사슴), 바위 정원(호랑이), 연못(펭귄), 사바나(코끼리·기린·얼룩말) 네 서식지로 재구성했습니다. 불규칙한 곡선 경계와 관람 난간, 기존 배경용 나무·바위, 원본 그늘막·먹이통·공, 회색 돌 순환 관람로, 방문자 정자·피크닉·분수·입구 캐노피를 배치했습니다. 일반 목장과 달리 생산 시설 없이 관람 동선과 각 서식지 환경을 구성했습니다. 서식지의 굴곡을 따라 안전 충돌 구역을 만들고 관람객의 이동 영역에서 제외했습니다.

기존 22×22m 건축 범위와 저장된 입구·방향을 유지합니다. PetTownZooLayout이 포장, 난간, 동물, 관람 지점과 식재에 공통 좌표를 제공합니다. 동물원 경로의 기존 저장 방문 slot도 0~3을 유지하며 새 관람 지점으로 대응합니다. 산책로는 선택한 Stylized Stone Floor 005를 사용합니다. 바닥 높이는 약 0.045m이며 원본 지형을 파서 내려가는 지하 우리나 조류 돔은 이번 구현에 포함하지 않았습니다.

첨부 GLB는 glTFast로 임포트하고 원본 형상을 재질별로 합친 프리팹으로 연결했습니다. glTF baseColorFactor를 URP/Lit 색상으로 전달해 원본의 코끼리 색·기린 무늬·얼룩말 줄무늬를 유지합니다. 난간은 원본 형상을 짙은 금속색의 별도 재질로 변환했습니다. 원본 GLB에는 애니메이션이 없어 새 세 종은 정적 전시입니다. 기존 세 종의 idle 애니메이션과 플레이어/NPC 이동 코어는 바꾸지 않았습니다.

## 동물 관리와 저장 호환

관리 가능한 종을 기존 사슴·호랑이·펭귄 뒤에 코끼리·기린·얼룩말 순으로 추가했습니다. 기존 3칸 배열은 Array.Resize로 6칸으로 확장하며 보유 수를 보존하고 새 종은 0마리로 시작합니다. 구매 목록·가격·정원·총 동물 수·먹이 소모·표시 갱신 해시도 6종에 대응합니다. 코끼리 1마리/1500G, 기린 2마리/1100G, 얼룩말 3마리/700G이며 기존 세 종의 가격·정원은 유지됩니다. 전체 정원은 12마리입니다. 새 동물을 사용자 마을에 무료로 지급하거나 자동 구매하지 않았습니다.

## 잔디와 돌길 경계

공원·호수·동물원의 잔디는 기존에 GHIBLI의 Grass_ground_Base_Color 재질과 일부 장식 풀 위주였습니다. 넓은 초록 부분을 빽빽한 입체 잔디로 그린 상태는 아니었습니다. 추가 개선은 다음과 같습니다.

- 시설 전용 MeadowGround 셰이더로 실제 GHIBLI 잔디 텍스처를 2.1회/m로 반복하여 지나치게 커 보이던 무늬를 작게 만들었습니다. 월드 전체의 기존 지형 셰이더와 원본 에셋은 변경하지 않았습니다.
- 승인된 Ghibli_Grass_03/02의 원본 풀 메시를 사용하고, 원본 임포터 설정을 건드리지 않는 읽기 가능한 복제 메시를 생성했습니다.
- 시설별로 위치가 고정된 식재를 재질별 2개 메시로 묶었습니다. 공원 243군락/53884정점, 호수 163군락/36164정점, 동물원 431군락/95526정점입니다. 별도 충돌체가 없는 장식이며 시설 삭제 시 소유 메시·재질을 정리합니다.
- 길 주변은 더 짧은 풀, 내부는 풀 없는 작은 구역이 섞이도록 했고 관람 통로·연못·가구 충돌 영역을 피합니다. 길 가장자리에 약 22cm의 부드러운 흙·잔디 혼합 재질을 넣었습니다.
- 시설 잔디는 카메라 중심 재생성이 없고 거리 Fade를 끈 별도 재질을 사용해 한꺼번에 중앙으로 축소되거나 사라지는 문제를 피합니다. 기존 월드 전체 잔디 예산/시스템은 유지합니다.
