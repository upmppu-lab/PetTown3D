# 밭·카페·병원 심화 적용 (2026-10-28)

## 1. 농장·목장
- 밭 확장 2단계: 9칸 → 11칸(1,500G) → 12칸(2,500G). 새 밭 위치는 농장 하단/좌측.
- 계절 작물: 7일마다 계절 전환(봄→여름→가을→겨울). 제철 작물은 씨앗 20% 할인, 판매가 +30%.
  - 봄: 양배추·당근 / 여름: 토마토·옥수수 / 가을: 밀·호박 / 겨울: 감자
- 생산 동작: 성체 소·양 위에 우유병/양모 표시가 떠서 회전하고, 수확 시 몸이 살짝 튀는 연출.

## 2. 카페
- 메뉴 5종: 기본, 채소 샌드위치, 우유 푸딩, 당근 옥수수 수프(Lv.3), 감자 그라탱(Lv.5).
  - 수프: 당근2+옥수수1+기본3 → 3인분, 150G, 13초
  - 그라탱: 감자2+우유1+기본4 → 3인분, 175G, 15초
- 재료 준비 목록은 해금된 메뉴만 표시. 기존 저장은 보관 배열을 자동 확장(기존 수량 유지).

## 3. 병원
- 진료 4종: 예방검진, 치료, 정밀검진(Lv.4, 230G, 소모품2, 15초, 이상 없으면 7일 안정), 입원 치료(Lv.6, 450G, 소모품3, 24초, 휴식일 없이 즉시 퇴원).
- 환자 목록에서 펫을 누르면 진료 선택 창이 열림. 직원 자동 치료는 기존대로 자동 선택.

## 검증
- 컴파일 오류 0, 상태 로직 편집기 테스트 통과(레시피 소모/해금/배열 확장/진료 가능 조건).
- 미검증: Play 모드 실제 UI 표시, 새 밭 3D 모습, 입원 치료 실제 진행.
