# 주민 펫 건강·병원 검진·치료 — 2026-10-27

주민의 펫 정보 → 건강 상태에서 건강·최근 검진·회복 상태를 확인하고 실제 병원을 선택합니다. 병원 운영 → 병원 환자·건강에서도 네 상태(건강함/컨디션 확인 필요/진단 후 치료 필요/회복 중)를 확인하고 방문을 안내합니다.

## 플레이 흐름

1. 주민 펫의 피로·배탈·피부 트러블은 게임 안에서 플레이한 새날에만 드물게 발생합니다. 진단 전에는 컨디션 확인 필요로 표시합니다. 기존 펫과 새 건강 기록은5일 유예를 받습니다. 가능한 날에 펫 ID와 게임 날짜를 이용한 고정 난수로6% 판정하며 같은 날 반복 호출·재시작으로 다시 굴리지 않습니다.
2. 예방검진은 실제 주민·펫·수의사가 진료 지점에 도착해야 시작됩니다. 기존 수동 진료도 가능합니다. 소모품1개, 기본10초, 이용료140G입니다. 완료 즉시 진단 결과를 저장하고 실제 수납은 접수대에서 별도로 처리합니다.
3. 진단받은 증상이 있으면 다음 방문은 치료입니다. 검진을 마치고 귀가한 뒤 같은 날에도 안내할 수 있습니다. 치료는 소모품2개, 기본16초, 이용료260G이며 직원 교육 효율을 적용합니다. 완료 후 피로는1일, 나머지는2일의 새날 휴식을 거쳐 건강함으로 돌아옵니다. 회복 중에는 신규 병원 방문을 받지 않습니다.
4. 병원 자동 방문과 직원 자동 업무는 기존 설정을 사용합니다. 새 자동 치료 허용은 기본 꺼짐입니다. 켜야 진단받은 펫을 자동 치료 방문으로 안내합니다. 직접 치료 안내는 가능합니다. 끄는 동작은 신규 자동 치료 안내를 중단하며 이미 받은 방문은 마칠 수 있습니다.

상태 변화는 주민 펫에만 적용했습니다. 매장 분양 펫·가축·동물원 개체의 건강, 입원 병상·추가 검사 종류·전용 치료 애니메이션과 실제 주택에서 쉬는 행동은 이번 범위에 포함하지 않았습니다. 회복의 휴식 일수는 저장된 게임 상태이며 펫의 기존 이동·산책 코어를 바꾸지 않았습니다.

## 예약·중단·저장

- 검진1개/치료2개의 무게로 공용 소모품을 예약해 여러 병원의 중복 예약을 막습니다. 부족하면 방문하지 않으며 골드·소모품을 자동 구매하지 않습니다.
- 시작할 때만 소모품을 차감합니다. 직원/펫 부재·급여 미지급·가구 이동 시 기존 현장 대기/재인계 규칙을 따릅니다. 저장 후 같은 재료를 다시 쓰지 않습니다.
- 질병 발생 차수와 증상을 방문에 고정해 오래된 방문 결과로 다른 증상을 치료하지 않습니다. 검진/치료 결과는 한 번만 적용하며 영수증에 서비스·증상·결과를 남깁니다. 결제는 실제 도착 후 한 번만 처리합니다.
- 진료 전 취소는 예약만 해제합니다. 시작 후 취소는 소모품을 반환하지 않고 완료 전이면 진단/회복을 주지 않습니다. 진료를 실제 완료한 뒤 취소하면 결과는 유지되지만 수납하지 않은 수익은 없습니다.
- 검진과 치료는 각각 하루1회 수납하며 같은 날 검진 후 치료가 가능합니다. 회복은 같은 날짜에 중복 진행하지 않고 건너뛴 날짜를 소급하지 않습니다. 시설 방문 중에는 새 증상 판정과 휴식 일수 진행을 건너뜁니다.
- 건강 저장 버전이 없는 기존 JSON은 건강함과 초기 유예로 이관합니다. Unity가 누락 객체를 빈 객체로 만드는 경우도 버전 표시로 구분합니다. 이전 완료 방문은 기존140G로 수납할 수 있습니다.
- 기존 카페 주문·재료·가격과 요리사 흐름을 유지합니다. 새날 처리는 기존 시간/포커스 정지 규칙을 따릅니다.
