# 주민 펫 동행 및 산책 — 2026-10-26

농장·목장은 사용자 요청에 따라 보류하고 주민 소유 펫의 3D 동행과 산책을 추가했습니다. 전체 잔여 시스템 완료 보고서가 아닙니다.

## 사용 방법과 구현 범위

- 주민 → 함께 사는 펫 → 산책·펫 정보에서 실제 모델 썸네일과 산책 시작/종료 버튼을 표시합니다. 선택하면 상세 화면을 바로 엽니다.
- 주민 한 명당 소유 펫 한 마리를 선택합니다. 산책 선택은 기존 진행 저장 JSON의 선택적 필드로 저장합니다. 기존 주민은 기본적으로 산책을 선택하지 않은 상태입니다.
- 실제 걷기 클립을 확인한 기존 강아지 2종과 페럿을 사용합니다. 고양이·토끼는 다른 동물 모델로 대체하지 않고 준비 중으로 표시합니다.
- 카페·예방검진 방문 중에는 방문에 등록된 펫을 우선 동행 대상으로 삼습니다. 시설 도착·수납 판정은 기존 주민 방문 상태가 담당하며, 이번 작업에서 동물의 도착을 추가 수납 조건으로 바꾸지 않았습니다.
- 새 펫 전용 NavMeshAgent가 주인의 뒤쪽 경로를 따라갑니다. 기존 주민의 배회·시설 경로·속도·애니메이션 드라이버는 변경하지 않습니다. 펫은 주인보다 낮은 회피 우선순위를 사용합니다.
- 도달 가능한 경로와 높이 차를 확인합니다. 일시적인 길 막힘은 재시도하고 경로가 없으면 정지합니다. 강바닥의 잠긴 경로를 거절하는 보수적 검사를 추가했습니다. 순간이동으로 따라잡지 않습니다.
- 실제 펫 이동과 주인 이동이 함께 측정되고 서로 가까울 때만 산책 거리에 반영합니다. 20m당 펫 XP +1, 하루 최대 5XP입니다. 정지·멀리 떨어짐·큰 위치 점프는 보상에서 제외합니다. 부분 산책 거리는 재접속 시 이어 누적하지 않습니다.
- 정지하면 걷기 클립을 중단하고 기본 자세로 복귀합니다. 임포트된 뼈의 위치 키는 새 펫 인스턴스에서만 고정하여 모델과 이동 루트가 분리되는 현상을 막습니다. 회전 애니메이션은 재생합니다.

## 발견한 원인과 처리

1. 실제 GLB의 단일 걷기 클립 이름은 `Armature|Unreal Take|baselayer`입니다. 기존 NPC 분류기의 `lay` 제외 규칙에 `baselayer`가 걸립니다. 기존 NPC 규칙을 바꾸지 않고 새 동행 기능에 해당 모델의 단일 클립 선택을 추가했습니다.
2. 펫 GLB의 `sharedMesh.bounds`가 비어 있어 기존 범용 높이 측정으로는 크기를 맞출 수 없었습니다. 새 펫에만 유효한 `SkinnedMeshRenderer.localBounds`의 8개 모서리를 변환해 크기를 계산합니다. 강아지 정지 높이 약 0.75m, 페럿 약 0.42m를 실제 실행에서 확인했습니다.
3. 경로 실패를 에셋 실패와 구분하여 일시적인 통행 문제로 펫 생성이 영구 중단되지 않도록 했습니다. 소유자별 재시도 간격과 전체 생성 간격을 둡니다.
4. 종료·소유 관계 변경·외부 오브젝트 제거 시 새 펫 및 복제 클립과 애니메이션 등록을 정리합니다.
