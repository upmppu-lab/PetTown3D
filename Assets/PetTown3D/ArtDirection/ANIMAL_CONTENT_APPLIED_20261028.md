# 동물 전용 기능 · 콘텐츠 심화 적용 (2026-10-28)

## 3. 동물
- 펫 등급: 별 1~5 + 희귀 유전자(금빛/은빛/무지개). 새끼는 부모 평균 별에 변동·유전자 보너스를 받고, 분양가에 반영(별당 +15%, 유전자 x1.5).
- 자동 교배(Lv.5): 20초마다 암수 한 쌍을 골라 최대 2쌍까지 자동 시작(별/유전자 점수가 높은 쌍 우선). 교배 창에서 켜고 끔.
- 동물원: 우리 넓히기 2단계(1,200/2,400G, 모든 종 정원 +1), 전담 사육사(Lv.4, 800G, 먹이 재고로 매일 급식·청소), 방치 시 질병(관람 중지, 300G 진료), 건강한 같은 종 2마리 이상이면 4일마다 새끼 탄생.

## 4. 콘텐츠
- 눈 날씨: 겨울(4번째 계절)에는 비 대신 눈. 눈 파티클 + 효과음.
- 효과음(에셋 없이 코드로 생성): 비, 겨울 바람, 여름·가을 밤 귀뚜라미, 봄·여름 낮 새소리.
- 레벨 해금표: 퀘스트 게시판 → 레벨 해금표. 밭 넓히기는 Lv.3 / Lv.6.
- 계절이 바뀌는 날 알림, 14일마다 마을 축제(주민 행복도 +3, 지원금).
- 새 하루 의뢰 2종: 동물원 식구 돌보기, 새 생명의 소식.

## 하지 않은 것 (정직하게)
- 케이지 모델·펫 입장 연출, 먹기/치료/앉기/미용 애니메이션, 토끼 아트 통일: 3D 에셋·애니메이션 작업이라 이번에 하지 않음.
- 새·수족관 배정: 현재 펫 종류가 개·고양이·토끼·페럿 4종뿐이라 대상이 없음.
- 동물원 자유 배회 3D 이동: 미구현(정원/우리 확장 상태만 반영).
- 공원·호수 신규 활동, 공공시설·주택 종류, 도감·손님 종류 확대: 미구현.
- 병원/카페 배치 회귀 테스트: 편집기 상태 테스트만 수행.

## 검증
- 컴파일 오류 0. 상태 로직 테스트(우리 확장, 사육사, 질병, 번식, 유전, 날씨, 해금표) 통과.
- 미검증: Play 모드 UI/눈 파티클 모습/효과음 크기/실기기.
