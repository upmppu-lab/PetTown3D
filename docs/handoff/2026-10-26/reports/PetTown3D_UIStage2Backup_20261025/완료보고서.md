# 통합 개발 2단계 — 공통 UI·건물 목록창
2026-10-25. 기존 HUD와 실제 건설 진입점을 보존한 새 목록창을 추가했다.
기존 변경 파일: PetTownGame.cs(메뉴/선택/입력 차단 연결), PetTownCustomizationUI.cs(검색 초점을 기존 입력 차단 신호에 합침).
신규: PetTownCatalogWindow.cs, PetTownUITheme.cs 및 .meta. 전용 Resources/UI/Kenney에 원본 PNG 3장을 복사했다. 원본 Kenney PNG/폰트, 캐릭터 이동·애니메이션, NPC 및 저장 코드는 수정하지 않았다.
기능: 한글 TMP 동적 폰트, Kenney 9-slice, 실제 8개 건설 항목, 이름 검색, 데이터별 카테고리, 이름/가격/면적 정렬, 스크롤, 선택 상세와 실제 비용/크기, 기존 배치·도로 선택 연결, 닫기/ESC, 기존 목록 복귀 및 다시 열기.
주민 주택의 실제 prefab 미리보기 공급자를 연결했다. 다른 절차적 건물은 전체 prefab이 없어 현재 이름/비용/설치 면적 카드로 표시한다. 모든 건물의 완성 3D 썸네일이 구현됐다고 보고하지 않는다. 전체 HUD 교체는 6단계 범위다.
검증: Unity C# 컴파일 및 Console error 조회 0. 실제 Play에서 검색 집=1개, 주거=2개, 빈 검색=0개, 면적 정렬, 주민 주택 선택→기존 Build 모드 전환, 건물/코인/저장 불변 확인. 기존 목록/다시 열기와 Road 선택=8 정상.
검색 초점이 기존 UI 입력 차단 getter에 전달되고 닫은 뒤 해제됨을 확인했다. NanumSquare TMP에 가나다/집/의자 동적 glyph 추가 성공, missing 없음.
1280×720 가로 및 720×1280 세로 GameView 레이아웃을 확인했다. 목록/상세 영역이 양수 크기이며 세로에서는 한 열 목록과 하단 상세로 바뀐다. 실제 Android/iOS 기기 테스트는 하지 않았다.
캡처 도구가 Overlay UI를 제외하므로 캡처 동안만 Canvas를 ScreenSpaceCamera로 바꿨다가 즉시 Overlay로 복원했다. 캡처 색상에는 카메라 후처리가 영향을 줄 수 있다. 테스트 해상도 프리셋을 제거하고 원래 GameView 크기를 복원했다.
Play를 중지하고 원본 저장 문자열/자본 플래그를 복원했다. 씬 isDirty=false. 테스트 결과 JSON 및 캡처를 함께 보관했다.
기존 펫/물고기 모델 일부의 ANIMATION NOT FOUND 경고와 MCP 중복 요청 경고가 관찰됐다. 해당 애니메이션 루틴은 바꾸지 않았으며, 이 단계에서 모든 기존 애니메이션까지 정상이라고 검증한 것은 아니다.
사용자가 추가한 가구 격자/90도 회전/프리뷰 요구는 3단계의 가구 저장 기반과 함께 진행한다.
