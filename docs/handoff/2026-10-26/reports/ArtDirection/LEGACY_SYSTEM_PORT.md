## 사용자가 지정한 우선순위와 현재 상태

모바일 HUD의 작은 독립 원형 버튼, 하단 왼쪽 건설/꾸미기/가방/펫샵 관리, 오른쪽 중앙 캐릭터/주민/펫/설정, 상단 소형 칩, 글자 수에 맞는 검은 안내창을 구현했다. 실제 Game View 확인: `Captures/MobileStyle/compact-hud-light-oak.png`. 안내창 짧은 문장 83.32 / 긴 문장 297.78 논리 픽셀로 자동 폭 변경 검증.

밝은 원목 바닥은 판자 길이/폭/이음매/색이 다른 단일 메시이며 물리 바닥은 기존 것을 유지한다. 실제 주광 부드러운 그림자, 140m 거리/2캐스케이드/4096 shadowmap을 적용했다. 기기 성능은 별도 검증 필요.

현재 사용자 피드백에 따라 자연환경을 먼저 수정 중이다. Quaternius Stylized Nature MegaKit Standard의 실제 FBX/텍스처/정점 음영을 쓰는 숲 라이브러리와 입체 잔디 인스턴싱을 추가했다. 컴파일/시각 검증이 끝나기 전 완료로 보지 않는다.

## 이식 순서

1. 버전이 있는 독립 진행 데이터: 플레이어 XP/레벨, 펫 XP/레벨/성장, 서비스 행복도. 기존 마을 저장과 호환되는 선택적 확장으로 저장.
2. 새 HUD에 실제 레벨/경험치와 행복도 수치/설명 연결. 기존 캐릭터 꾸미기 기능 유지.
3. 개체별 재고와 고객 요청에 맞는 분양 선택, 가격 근거, 분양 이력/XP 연결. 현재 단순 E키 판매와 중복 차감 방지.
4. 입주/이탈은 실제 주택 정원과 NPC를 일치시킨 후 도입. 데이터가 없는 기능은 완료로 표시하지 않음.
5. 직원/배송/교배/미니게임/카페·병원 영업/퀘스트/도감 등은 별도 모듈로 확장. 이번 화면 작업만으로 이들까지 구현했다고 주장하지 않는다.
