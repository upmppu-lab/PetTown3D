# PetTown3D 2단계 — 격자 미리보기

## 구현 범위
- 기본 1m 격자. PetTown3D_GAME의 PetTownGame 컴포넌트에서 Construction Grid Size, Origin, Radius를 조정 가능.
- 건설 모드와 최초 상점 설치 중에만 표시. 탐험·꾸미기·커스텀에서는 숨김.
- 커서 주변 기본 24m 범위만 하나의 메시로 생성. 5칸마다 기준선을 색상·굵기로 구분하고 가장자리는 페이드.
- 실제 TerrainLayer 높이를 따라 표시. 물·지형·도로의 원본 렌더링 코드는 변경하지 않음.
- 새 건물 미리보기와 실제 설치는 같은 BuildingPlacementPoint를 사용해 X/Z 스냅 후 실제 지형 높이를 계산.
- 기존 건물·저장 항목의 좌표를 다시 스냅하지 않음. 가구의 기존 배치 방식과 자유 도로 입력도 유지.
- 같은 셀 안에서는 메시 재생성/높이 샘플링 없음. 인접 셀은 높이 캐시 재사용. FlattenTerrain 이후 캐시 무효화.
- 격자에는 콜라이더가 없고 NavMeshModifier.ignoreFromBuild로 경로 생성에서 제외.

## 변경 파일
- 수정: Assets/PetTown3D/Scripts/PetTownGame.cs — 설정 3개, 공통 스냅과 격자 표시 연결, 지형 편집 시 캐시 갱신.
- 추가: Assets/PetTown3D/Scripts/PetTownBuildGrid.cs (+meta) — 좌표 변환, 설정 크기 검증, 스냅.
- 추가: Assets/PetTown3D/Scripts/PetTownGridOverlay.cs (+meta) — 국소 메시, 높이 캐시, 표시/숨김과 자원 정리.
- 추가: Assets/PetTown3D/Resources/Materials/PetTownBuildGrid.shader (+meta) — 격자 전용 URP 셰이더. 기존 셰이더는 수정하지 않음.

## 실제 검증
- Unity 6000.6.6f1에서 C# 컴파일 및 격자 셰이더 패스 컴파일 확인. 최종 콘솔 error 항목 0건.
- 0.25/0.5/1/2m 셀, 음수 좌표·원점 오프셋, 최근접 스냅 및 재스냅 동일성 통과.
- 기본 메시 9,600정점, 초기 높이 샘플 1,825개. 같은 셀은 재생성/재샘플 0건. 인접 셀의 높이 캐시 재사용 확인.
- 실제 지형 콜라이더와 격자 높이의 오차: 지정한 4.5cm 띄움 기준 최대 약 2cm (선의 가로 폭에 따른 차이 포함).
- 실제 Place() 경로: 입력 (-80.4,60.3) → 설치 (-80,60). 예상 미리보기 위치와 실제 설치 위치 일치. 기존 5개 건물의 위치·회전 변경 없음.
- 탐험/꾸미기/커스텀 격자 숨김, 도로 선택 시 건물 스냅 우회, 실제 건물 설치 후 격자 캐시 무효화 통과.
- Play에서 NPC·동물의 경로/이동 속도 확인. 실제 게임 화면 스크린샷 보관.
- 기존 파일 해시 비교: PetTownGame.cs만 변경됨. 플레이어·NPC·저장·도로 메시·물 셰이더/머티리얼 코드 보존 확인.
- 테스트 중 추가한 건물은 Play 종료로 제거. 원본 PlayerPrefs 저장 문자열과 자본 플래그 복원 후 일치 확인. 저장 형식 변경 없음.
- Unity는 최종 Play 중지 상태. 기존 씬 파일을 저장하지 않음.

## 미검증 및 다음 단계
- 마우스로 건물을 연속 배치하는 장시간 테스트와 전체 프레임 성능 측정은 미수행. MCP로 실제 Place() 및 표시 경로를 검증함.
- 첫 메시 생성은 MCP 검사에서 약 26ms였으며, 반사 호출/초기화 비용을 포함한 참고치. 같은 셀의 지속적인 생성 비용은 없음.
- 건물 회전, 출입구 표시, 도로 자동 방향 추천, 점유 칸수 정의, 새 안전 검사/색상, 직선 도로, 도로 저장 보완은 이번 단계에 포함하지 않음.
- 기존 미리보기 색은 여전히 자금 기준이며 설치 안전성을 보장하지 않음. 종류별 기존 footprint 불일치는 다음 단계의 공통 정의 작업에서 처리할 예정.
- 최초 상점 설치도 격자 건설로 취급. 건설 모드의 자유 도로에는 격자를 보여 주지만 드래그 좌표를 스냅하지 않음.
- 3단계 구현은 아직 시작하지 않음.
