2026-10-25 / Unity 6000.6.6f1

## 복구와 보호
변경 전 Git HEAD d92b1b8과 기존 변경을 확인했다. 이 폴더에 대상 소스 3개, Git 상태/HEAD, 파일 해시, 원본 PlayerPrefs JSON을 백업했다. 전체 프로젝트 백업은 아니다. 사용자 변경을 초기화하거나 임의 커밋하지 않았다.
플레이어 제어/커스터마이징/기존 NPC 동작/강 셰이더/기존 에셋/씬은 수정하지 않았다. 줄바꿈을 정규화한 NPC 이동 구간 및 Height~BuildWorld 구간은 원본과 동일하다.

## 5단계
신규 건물의 격자 스냅에 도로 앞줄 정렬 보조를 연결했다. 가까운 축 방향 도로에 입구가 향할 때 최대 4m 이내에서 조정하고 주변 같은 방향 건물 앞줄을 참조한다. 종방향은 격자에 맞추며 최소 간격은 안전 검사가 보장한다. 급한 곡선/대각선과 수동 회전은 자유 격자 배치를 유지한다. 기존 건물은 이동시키지 않는다. 건설 안내 아래 버튼으로 정렬을 끌 수 있다.
PetTownGame.GetRoadConnection(PetTownBuildingPlacement)로 Connected, Entrance, RoadEdge, Gap, Grade, RoadId를 조회한다. 입구~도로 공간의 물/경사/다른 건물/물리 장애물도 확인한다. Dirt/Paved 데이터 기반만 제공하며 만족도·이동 속도 보너스는 적용하지 않는다. 향후 연결 보행로를 만들 수 있는 양끝 좌표를 제공하되 자동 생성하지 않는다.
기본 연결 거리 roadGap은 2.5m이며 Inspector에서 조절한다. 반 칸의 반올림 여유를 정렬 간격에서 고려한다. 기존 편집기 메모리 설정도 2.5m로 맞췄으며 씬 에셋은 저장하지 않았다.
평탄화가 기존 도로 중심/가장자리를 5cm 넘게 바꾸는 위치는 RoadEarthwork로 거부한다. 원래 평탄화 알고리즘이나 기존 도로 메시를 바꾸지 않는다. 기복이 있는 곳에서는 정렬 후보도 거부될 수 있다.
선택적 roadVersion=1/roads 필드에 경로 점·폭·모드·등급·ID를 저장/복원한다. 기존 건물 types/x/z와 constructionVersion=2는 유지한다. 사용자 도로만 저장하여 매번 자동 생성되는 배경 마을 길이 중복되지 않는다.
예전 kind=8 항목에는 경로 점이 없어 모양을 복구할 수 없다. 해당 항목은 원래 좌표로 보존하며 임의 길을 만들거나 삭제하지 않는다. 이미 소실된 경로는 실제 경로 점이 있는 원본 백업이 있어야 복원 가능하다.

## 6단계
Road 선택 후 도구 버튼으로 자유 곡선/격자 직선 모드를 전환한다. 기본 곡선 드래그는 유지한다.
직선은 큰 드래그 축을 따라 수평/수직으로, 양 끝은 격자에 맞춘다. 폭 2.2m와 기존 비용·제외 영역·지형 높이·원형 마감·UV 생성기를 재사용한다.
드래그 시작 시 모드를 고정하고 드래그 도중 전환하지 않는다. 직선만 기존 입구 끝점 보정으로 휘어지지 않도록 선택 인자로 끄며 곡선은 유지한다.
기존 도로의 유한 구간 교차점 및 끝점 근접 연결을 인식한다. 기존 메시를 병합/변형하거나 NPC 길찾기를 교체하지 않는다. 교차부 외관 개선은 별도 그래픽 범위다.

## 검증 및 한계
Unity 컴파일 후 Console error 조회 0. 독립 검사는 정렬, 수동 회전 유지, 물/장애물 연결 거부, 도로 없는 상태, JSON 왕복, 수평/수직·원점·0길이·교차점 검사를 통과했다.
실제 Play에서 두 모드 도로 생성/비용, 정렬 버튼과 모드 버튼 이벤트·텍스트를 확인했다.
재실행 전후 사용자 도로 2개의 전체 저장 레코드(모든 경로 점·폭·모드·ID)가 동일했다. 건물 6개의 위치/회전도 동일하며 연결 조회 정상. 자동 길 포함 총 도로 3개로 중복 증가하지 않았고 legacy 항목 2개도 유지됐다.
최종 보완 후 (-60,1.34,63)에 도로 연결 상태로 실제 주택 설치, 모델 맞춤 후 carving 장애물 및 연결 조회 true, 경로 갱신 완료를 확인했다. 마지막 순간 NPC 6명과 동물 3마리는 이동 중, NPC 2명은 경로 없이 정지 상태였다. 모든 NPC가 항상 움직인다고 검증한 것은 아니며 기존 행동 루틴을 바꾸지 않았다.
Play 종료 후 원본 PetTown3D_Save 및 시작 자본 플래그를 동일하게 복원했다. 테스트 건물/도로는 씬에 저장하지 않았다. test-results.json 참조.
물리 마우스·모바일 터치 전체 시나리오, 모든 모델, 장시간/대규모 부하는 미검증이다. MCP로 실제 Place/PlaceRoadPath 및 버튼 이벤트를 실행했다. 샘플 기반 경사/네비게이션 검사는 보수적이다.
후속 UI·자연환경 작업은 첨부 지시대로 분석만 진행한다.
