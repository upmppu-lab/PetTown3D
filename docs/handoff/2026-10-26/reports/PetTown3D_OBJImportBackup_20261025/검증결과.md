# OBJ Import 검증
2026-10-25
대상: Assets/kenney_furniture-kit/Models/OBJ format/bathroomCabinet.obj
Import 전에는 파일은 존재하지만 부모 폴더/OBJ가 AssetDatabase에 등록되지 않았고 .meta도 없었다.
명시적 Import 후 UnityEditor.ModelImporter로 등록됐다. 정점 100개, 삼각형 108개, wood/woodDark/metal의 URP/Lit 재질 연결을 확인했다.
원본 OBJ와 MTL의 SHA256은 백업 전후 동일하다. Unity가 새 에셋 폴더 등록을 함께 처리하여 .meta와 Import 캐시를 생성했다.
씬 배치/게임 코드/저장 데이터 변경은 하지 않았다. 최종 Play 중지, 씬 isDirty=false.
같이 등록된 Furniture Pack의 .blend는 Blender 미설치 오류를 기록했다. FBX/OBJ 대체본이 있어 Blender 설치는 수행하지 않았다. 기존 파일을 삭제/이동하지 않았다.
분석용 mainTexture 질의로 GroundBlend의 없는 _MainTex 접근 로그가 1건 있었으며 OBJ Import 오류와는 구분된다.
원본 백업과 해시는 이 폴더의 bathroomCabinet.obj/.mtl, before-hashes.json에 있다.
