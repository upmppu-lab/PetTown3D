# PET TOWN 3D — Unity 플레이 가능한 프로토타입 (v0.1)

## 중요
이 파일은 **전체 완성 게임이 아닌, 실제 조작 가능한 첫 번째 3D 프로토타입**입니다.
기존 Pet Town의 소스코드나 저장 데이터를 수정하지 않습니다.
첨부한 3개의 문서는 게임 기획 참고용이며, **원본 JS 전체 코드가 없으므로 기존 기능을 모두 이식한 것은 아닙니다.**

## 실행
1. Unity Hub > Add > Add project from disk > 이 폴더 선택.
2. Unity 6 에디터로 프로젝트 열기. 처음 열 때 패키지 가져오기가 완료될 때까지 기다리세요.
3. 상단 메뉴 **Pet Town 3D > Open Playable Scene** 클릭.
4. **Play** 클릭.
5. 게임 시작 시 지도에서 강을 피한 땅을 클릭하여 펫샵 위치 선택.

## 지금 가능한 기능
- 220×220 유닛 크기의 절차적 3D 지형: 언덕, 강, 호수, 드문 나무와 풀
- 시작 펫샵 부지 자유 선택, 심즈식 개방형 3D 실내(가구와 고객 확인)
- 펫샵 운영 기초: 펫 재고, 자동 방문 고객, 판매 수익, 재주문
- 주택, 카페, 병원, 공원, 호수, 동물원, 도로 건설(기초 모델)
- 펫샵 가구 설치(기초 모델)
- 내 캐릭터의 헤어/얼굴/몸통/다리/소품 분리 구성 및 교체 지점
- 주민/직원용 단일 루트 오브젝트(추후 Meshy 모델로 교체 가능)
- 먼 지역 다크 펫샵 마을의 임시 3D 건물
- 저장/불러오기(기본 건물과 경제 상태; PlayerPrefs)

## 조작
- WASD: 캐릭터 이동
- 마우스 휠: 확대/축소
- 마우스 가운데 버튼 드래그: 카메라 이동
- 왼쪽 패널: 건설, 가구, 캐릭터 커스터마이징, 펫 주문
- 건설/가구 모드: 땅 클릭하여 설치
- F5: 저장
- Esc: 일반 플레이 모드

## 모델 교체
Hierarchy의 PLAYER_Customizable_3D 아래에
FACE_REPLACEABLE / HAIR_REPLACEABLE / BODY_REPLACEABLE /
LEFT_LEG_REPLACEABLE / RIGHT_LEG_REPLACEABLE / ACCESSORY_REPLACEABLE이 있습니다.
각 건물은 *_REPLACEABLE 루트에 묶여 있습니다.
NPC는 NPC_SINGLE_MODEL_REPLACEABLE 루트입니다.
현재는 Unity 기본 도형이므로 Meshy AI FBX/GLB(변환 필요) 에셋으로 나중에 교체 가능합니다.

## 기술 정보
- Unity 6 계열 / Built-in Render Pipeline / Legacy Input Manager
- 외부 에셋과 패키지 없이 기본 Primitive와 C#으로 제작
- 모든 월드 오브젝트는 Play 모드에서 생성되며, Play 종료 후 Unity의
  임시 오브젝트 편집 내용은 사라집니다. 장기 편집은 생성 코드를 변경하거나
  모델 프리팹을 별도로 만들어 연결해야 합니다.
- Unity 에디터에서 실제 컴파일 및 Play 테스트는 이 환경에서 수행하지 못했습니다.
- 첫 프로젝트 열기에서 ProjectVersion 차이가 나면 Unity가 자동 업그레이드할 수 있습니다.
- 프로젝트 원본을 유지하려면 별도 폴더에 압축을 풀어 사용하세요.
